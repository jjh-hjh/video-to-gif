# 帧间 Framegrab · 视频转 GIF

一个**单文件、完全离线**的视频转 GIF 工具。没有后端、没有第三方依赖、没有 CDN，双击 `index.html` 就能使用，视频文件不会离开本机。

## 功能

- 拖拽或点击导入视频，本地预览与播放
- 拖动时间轴两侧把手截取片段，支持键盘微调与「取当前」
- 时间轴缩略图预览，实时显示片段长度和预计帧数
- 帧率：8 / 12 / 15 / 24 FPS
- 输出宽度 120–960 px 可调，保持原始比例
- 颜色数量：32 / 64 / 128 / 256 色
- 全局自适应调色板 + Floyd–Steinberg 抖动
- 可设置无限循环或只播放一次
- 生成进度、随时取消、完成后立即预览和下载
- 适配桌面与手机屏幕，无需联网

## 使用方法

1. 用 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。
2. 拖入一段视频，或点击「选择视频」。
3. 在时间轴上拖动两侧把手，截取需要的内容。
4. 调整帧率、宽度、颜色、抖动和循环方式。
5. 点击「生成 GIF」，等待进度完成后预览并下载。

无需安装 Node.js、ffmpeg 或其他软件。直接双击 HTML 文件即可运行；需要分享时，只发送 `index.html` 也能保持完整功能。

## 浏览器与格式说明

视频解码能力取决于浏览器。推荐使用最新版 **Chrome / Edge**，并优先选择：

- **MP4（H.264 + AAC）**
- **WebM（VP8 / VP9）**

MOV、MKV 等格式能否读取，取决于系统与浏览器内置的解码器。如果提示无法解码，可先将视频转换为标准 MP4 再导入。

已知限制：

- 单次最多生成 **500 帧**，超长视频请先缩短选区或降低帧率。
- 输出宽度上限为 **960 px**，不会放大超过原片宽度。
- 部分由浏览器 MediaRecorder 直接录制、缺少时长元数据的 WebM 会无法读取时长，建议先转换为标准 MP4/WebM。
- 生成使用共享全局调色板；颜色越少、尺寸越小、帧率越低，文件越小。
- GIF 不含音频。
- 浏览器内存与 CPU 决定生成速度；大尺寸、高帧率、长片段会更耗时。

## 技术实现

整个工具是一个自包含 HTML 文件：

- **HTML5 Video + Canvas**：浏览器本地解码、定位和截帧
- **原生 GIF89a 编码器**：LZW 压缩、逐帧延时、NETSCAPE 循环扩展
- **中位切分调色板**：从片段中抽样多帧，生成全局自适应色板
- **Floyd–Steinberg 误差扩散**：可选的蛇形扫描抖动
- **Blob URL + `<a download>`**：完全在本地导出文件

所有处理都在浏览器主线程中完成，不发起任何网络请求，也不会上传视频。

## 快捷键与操作细节

- 点击时间轴任意位置：预览跳转到该时间
- 拖动橙色把手：调整片段起点 / 终点
- 聚焦把手后按 `←` / `→`：微调 0.1 秒
- 按住 `Shift` 再按方向键：调整 1 秒
- `Home` / `End`：跳到选区边缘
- 「取当前」：用视频当前播放位置设置起点或终点
